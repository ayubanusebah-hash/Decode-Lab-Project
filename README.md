Project 2: 
Exploratory Data Analysis
 
Objective:
To explore an e-commerce dataset, identify patterns and trends, and generate meaningful insights from the data.

Tools Used:
-	Microsoft Excel
-	PivotTables
-	Charts

Analysis Performed:
-	Calculated descriptive statistics such as mean, median, and count.
-	Used IQR to check for outliers.
-	Analyzed products, order status, payment methods, and coupon usage.
-	Created PivotTables and charts to visualize the data.
-	Identified patterns and notable differences within the dataset.

Key Insight:
The Chair had the highest total quantity sold, with 562 units. The analysis also showed no significant outliers in the Quantity column.

Outcome:
The project strengthened my ability to explore raw data, identify patterns and unusual values, and communicate findings using Excel-based analysis and visualizations.
