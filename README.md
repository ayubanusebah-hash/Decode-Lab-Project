PROJECT 1: Cleaned Dataset

The dataset contains 1200 records and 14 variables.
Data quality assessment revealed no duplicate records.
Missing values were identified only in the CouponCode column (309 records), which were treated as "No Coupon" because they represent customers who did not use discount codes.
Data types were verified and found appropriate.
Date variables were converted to datetime format, and additional time features (Year and Month) were created to support analysis.
