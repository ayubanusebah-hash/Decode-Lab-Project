Project 3:SQL Data Analysis

Objective:
To use SQL queries to analyze an e-commerce dataset and extract useful information from the data.

Dataset
-	The cleaned e-commerce dataset was imported from Excel into SQL Server as Sheet1$.
-	SQL Operations Performed:
-	SELECT – retrieved relevant columns from the dataset.
-	WHERE – filtered orders based on their status.
-	ORDER BY – arranged orders according to their total price.
-	GROUP BY – grouped orders by product.
-	COUNT – calculated the number of orders.
-	SUM – calculated the total sales/revenue.
-	AVG – calculated the average order value.

Outcome
The SQL analysis successfully demonstrated how SQL can be used to retrieve, filter, sort, group, and summarize data to generate meaningful insights from an e-commerce dataset.

Tools Used:
-	Microsoft Excel — data preparation/cleaning
-	SQL Server / SSMS — data import and analysis
